# Skills Directory

> The security-first directory of skills for Claude, Claude Code, and coding agents. Every listed skill is automatically security-scanned and graded A–F before it appears, so people and agents can filter to safe, vetted skills. Free, no login required.

- 650,507 indexed skills, 650,507 security-scanned
- Grade distribution: A: 626,413 · B: 15,441 · C: 5,240 · D: 2,110 · F: 1,303
- What makes this directory different: every skill gets an automated multi-rule security scan (credential reads, network exfiltration patterns, unpinned remote code, prompt-injection vectors) and a public grade with a per-skill report. Sponsors can never buy grades or hide findings.

## API for agents

Unlike other skill directories, Skills Directory has a public API. Agents can query the catalog directly:

- [API documentation](https://www.skillsdirectory.com/api-docs): full reference
- Search with a security filter: `GET https://www.skillsdirectory.com/api/v1/skills?q=<query>&securityGrade=A`
- Registry endpoint for installers: `GET https://www.skillsdirectory.com/api/registry/<slug>`
- Install any listed skill with the skills CLI: `npx -y skills add <owner>/<repo> --skill <name> --agent claude-code` (the exact command is shown on each skill page)
- Live security-grade badge (SVG): `GET https://www.skillsdirectory.com/api/skills/<slug>/badge`
